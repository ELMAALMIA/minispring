What happens when the context starts

AnnotationApplicationContext.scan("com.example")
1. Scan the package
ClasspathScanner
↓
2. Read definitions
BeanDefinitionReader
↓
3. Create post-processors first
BeanPostProcessor
→
4. Create each singleton
BeanFactory
↓
5. Resolve constructor args
DependencyResolver, recursive
↓
6. Invoke @PostConstruct
LifecycleMethods
→
7. Apply post-processors
may return a proxy
↓
8. Cache the singleton
↓
9. ContextRefreshedEvent
context is ready
close() → ContextClosedEvent → @PreDestroy in reverse creation order
