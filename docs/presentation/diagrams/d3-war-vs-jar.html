WAR or executable JAR: who owns the server?

The change Spring Boot really made
Before: WAR
Tomcat is installed and started
it owns the JVM and the lifecycle
↓
It loads your app.war
web.xml, ServletContainerInitializer
↓
Spring context starts inside it
Several apps, one JVM. Deploy = copy a file into a shared server.
Now: executable JAR
java -jar app.jar
your main() runs first
↓
Spring context starts
↓
...which starts an embedded Tomcat
a Maven dependency, nothing else
One app, one JVM, one container image. Deploy = run a process.
