An annotation does nothing. Something has to read it.

@Component is a sticker · reflection is the reader · the container acts
@Component
class AuditService {}
1. Your class, with a sticker
→
javap -v AuditService.class

RuntimeVisibleAnnotations:
  0: #14(); Component
2. Stored in the class file
→
type.isAnnotationPresent(
  Component.class)
3. Reflection reads it
4. ClasspathScanner keeps the class → BeanDefinition → bean
Change RUNTIME to CLASS and the annotation is dropped from the class file: the scanner finds nothing, silently
