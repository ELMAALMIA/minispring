How @Conditional decides what gets wired

Auto-configuration is a plugin on the container, not a power of it
1. Your beans are registered
the application first
→
2. Read the index
META-INF/minispring/
autoconfiguration.imports
→
3. Sort them
@AutoConfigureAfter
→
4. Evaluate conditions
on definitions, never instances
Matches → register what is still missing
@ConditionalOnMissingBean
Does not match → skip, and record why
the condition evaluation report
Auto-configurations register LAST — that is the only reason "unless you declared your own" can work
